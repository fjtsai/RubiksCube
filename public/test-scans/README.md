# Rubik's Cube Scanner Test Photos

These six SVG images simulate one legal scrambled 3x3 cube state for testing the camera scanner pipeline without a physical cube.

Scramble:

```text
R U R' F2 D L2 B U2 R2 F' D2 L U' B2 R' F L2 D'
```

Facelet string:

```text
DLUBUDBRFLBBLRFBRRDUUFFURDDULLRDFFDULRRBLLDDBLBFUBUFFR
```
